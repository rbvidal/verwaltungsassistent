10. BUILD-METHODE
-----------------------------------------------------------------
- QEMU 11.1 (Windows) mit WHPX-Beschleunigung (Fallback TCG).
- Provisionierung: cloud-init NoCloud über SMBIOS ds=nocloud;s=URL
  (Seed-ISO + HTTP-Server auf dem Build-Host). SMBIOS-Datasource nur
  im Provisionierungs-Boot; das ausgelieferte Image bootet ohne Seed.
- Appliance-Layout in staging/artifacts/provision.sh (idempotent,
  mehrfach ausführbar).
- Wichtige Build-Fixes (dokumentiert): voll-alloziertes RAW-Arbeits-
  Image (sparse-tail read errors), unique instance-id pro Provisioning-
  Lauf, deterministische Benutzeranlage (cloud-init-users-Modul),
  Ollama-Binary mit Retry/Resume, Docker-Images als Host-Export
  (docker load), Neo4j ohne env_file (NEO4J_PASSWORD würde als
  neo4j.conf-Setting interpretiert → Crash-Loop).
