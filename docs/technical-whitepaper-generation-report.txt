ARCHITECTURE VERIFIED (all statements in the paper)
---------------------------------------------------
- Single-pass retrieval; NO recursive searches, NO query rewriting
  (explicitly documented in DefaultRetrievalAugmentationService).
- Keyword search = SQL LIKE over chunk text (JPA), umlaut folding,
  TF-based heuristic. NOT tsvector, NOT BM25, NOT sparse vectors.
- Vector search = Qdrant collection mda_chunks, cosine, nomic-embed-text
  768-d, top 15.
- Graph search = Neo4j keyword doc match (<=10) + 2-hop traversal;
  node types DOCUMENT/ENTITY/CONCEPT/ORGANIZATION/REGULATION/...
  (no dedicated "Verfahren"/"Rechtsgrundlage" labels - generic node types).
- Fusion: rankingScore = (0.40 kw + 0.40 vec + 0.20 conf) x docTypeWeight;
  graph additive +0.15 x graphScore (cap 1.0); dedup per document.
- Reranking: deterministic score sort + DomainGate soft multiplier
  (1.0 match/neutral, 0.8 cross-domain). LLM cross-reranker
  (OllamaRerankingProvider) exists but is NOT registered/enabled -
  stated accurately in the paper.
- Evidence package: <=4 documents, <=3 chunks/document, <=500 chars per
  excerpt, coverage threshold 0.6, confidence-gap skip.
- Routing: DecisionRouter -> RULE_ENGINE (structured tables) else
  GRAPH_REASONING (Neo4j available) / HYBRID_RETRIEVAL.
- Rule tables: TV-L 2025 (EG 1-15 x Stufen 1-6), BRKG (24/12/6 EUR
  Tagegeld, 0.35/0.20 EUR/km, 80/20 EUR accommodation), AV §55 LHO Berlin
  (<500 / 500-1,000 / 1,000-10,000 / 10,000-100,000 / >=100,000 EUR;
  Bauleistung <=20,000 EUR). Exact values quoted.
- Intent: LLM semantic parser default (temperature 0, semantic-intent
  enabled=true), regex parser as emergency fallback; domains PROCUREMENT,
  BUILDING, HR, TRAVEL + GENERAL.
- Verification: separate verifier model (default qwen2.5:14b; validated
  qwen2.5:7b rollback documented in application.yml); default strategy
  pairwise; claim_batch strategy includes user question + critical rules
  ("retrieved candidates are NOT automatically evidence").
- Fail-closed: exact German wording
  "Für diese Frage liegen in der Wissensbasis keine ausreichenden
  Informationen vor." (DefaultGroundingService), citations cleared,
  zero-supported-claims condition.
- Grounding conditions: overallConf >= 0.20, >=1 citation >= 0.25,
  >=1 supported claim, zero unsupported claims.
- Confidence profile weights: source 0.2 / authority 0.25 / semantic 0.25
  / completeness 0.3.
- Models: chat qwen2.5:14b, verifier qwen2.5:14b (7B rollback option),
  embeddings nomic-embed-text 768-d, all via local Ollama.
- Ingestion: PDFBox primary + Tika fallback; fixed chunking 500/50 (web
  app); PostgreSQL chunks, Qdrant points, Neo4j LLM enrichment.
- Audit: audit_events (RETRIEVAL_EXECUTED with per-mechanism counts,
  MODEL_INFERENCE with strategy), execution trace, tiered citations,
  CSV export.
- Security: form login, BCrypt(12), CSRF, session registry, roles
  ADMIN/AUDITOR/ANALYST/USER; on-premise/air-gapped capable.
