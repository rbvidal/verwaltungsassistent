# reports/

Every benchmark run creates its own directory here (or anywhere else you
point `--output` at). Convention:

```
reports/
├── verifier/
│   ├── 3090-qwen36-27b/          # one directory per (GPU-)model run
│   │   ├── results.jsonl         # per-case results incl. raw responses
│   │   ├── summary.json          # machine-readable summary
│   │   ├── gpu.csv               # nvidia-smi samples (if available)
│   │   ├── README.txt            # human-readable summary
│   │   └── raw/<case-id>.json    # prompt + raw response per case
│   └── 3090-deepseek-r1-14b/ ...
└── generator/
    ├── 3090-qwen36-27b/ ...
    └── ...
```

Rules:

- A new `--output` directory is never overwritten unless `--force` is given.
- Nothing in this directory is generated by the suite itself; it only
  contains run results.
- `examples/smoke-outputs/` in the suite root contains sample outputs from
  the validation smoke runs (see the suite README).
