9. Validation — fieldErrors & globalErrors

fieldErrors (per-field)

Renders th:errors="*{field}" with the design system's .form-field__error class. Hidden when the field has no errors (th:if="${#fields.hasErrors(field)}").

Bitte geben Sie einen gültigen Wert ein.

globalErrors (object-level)

Iterates over ${#fields.errors('*')} and renders each global error as a .message--error banner. Silent when there are no global errors.
