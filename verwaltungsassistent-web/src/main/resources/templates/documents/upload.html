Dokument hochladen

Laden Sie Dokumente hoch, um die Wissensbasis aufzubauen. Die Dokumente werden anschließend automatisch indexiert und stehen für die KI-Analyse zur Verfügung.

Unterstützte Formate: PDF, DOCX, TXT, HTML. Maximale Größe: 50 MB pro Datei. Sie können mehrere Dateien in einem Schritt auswählen.

Lassen Sie das Feld leer, um den Dateinamen zu verwenden. Bei mehreren Dateien wird dieser Titel nur für die erste Datei verwendet.

Abbrechen

Mehrere Dokumente oder einen Ordner hochladen

Die Dateien werden einzeln über die bestehende Verarbeitungskette erfasst und indexiert. Eine fehlerhafte Datei bricht die übrigen Uploads nicht ab.
